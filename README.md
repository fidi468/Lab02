# Lab 02 — Linked List, Stack and Queue

## Overview
This project implements three data structures in Python through practical scenarios.

## Tasks
- **Task 1:** Spotify Playlist Manager — Linked List
- **Task 2:** Browser Undo History — Stack
- **Task 3:** University Printing Service — Queue

## Project Structure
- `src/` — Python source code
- `screenshots/` — Test screenshots
- `test_results/` — Performance measurements
- `report/report.pdf` — Final report
- `docs/` — Additional documentation

## Requirements
- Python 3
- Custom implementations of Linked List, Stack, and Queue.

## How to Run
```bash
python src/main.py
```

## Performance Testing
Insert, Search, and Delete operations are measured for 100, 1,000, and 10,000 songs. Results are saved in `test_results/`.
